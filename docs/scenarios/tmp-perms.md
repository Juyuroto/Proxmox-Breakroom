# Permission denied dans /tmp

**Type :** Panne · **Difficulté :** facile · **Dossier :** `scenarios/tmp-perms/`

## Énoncé

Ticket : « Depuis ce matin, les scripts des utilisateurs plantent avec "Permission denied" dès qu'ils créent un fichier temporaire. »

Objectif : tous les utilisateurs peuvent de nouveau utiliser /tmp, sans pouvoir supprimer les fichiers des autres.
