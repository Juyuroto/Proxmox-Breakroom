# Retrouver un fichier égaré

**Type :** Tâche · **Difficulté :** facile · **Dossier :** `scenarios/tache-find-secret/`

## Énoncé

Un fichier contenant le jeton de production (une ligne `API_TOKEN=prod-...`) a été égaré quelque part dans `/srv`, `/opt` ou `/var`. Attention, il existe des copies de test.

Objectif : écris le chemin complet du bon fichier dans `/root/reponse.txt`.
