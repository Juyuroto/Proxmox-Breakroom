# Dossier partagé d'équipe

**Type :** Tâche · **Difficulté :** moyen · **Dossier :** `scenarios/tache-shared-folder/`

## Énoncé

Les utilisateurs `alice` et `bob` existent déjà.

Objectif :
- un groupe `devs` contenant alice et bob ;
- le dossier `/srv/projet`, où ils peuvent tous les deux créer des fichiers ;
- les fichiers créés dedans appartiennent automatiquement au groupe `devs` ;
- les autres utilisateurs n'y ont pas accès.
