# Restaurer une table supprimée

**Type :** Tâche · **Difficulté :** moyen · **Dossier :** `scenarios/tache-db-restore/`

## Énoncé

Ticket : « Quelqu'un a supprimé la table `orders` de la base `shop` ! La sauvegarde de cette nuit est dans `/backup/shop.sql`. »

Objectif : la table `orders` est restaurée avec toutes ses lignes.
