# Durcir SSH

**Type :** Tâche · **Difficulté :** facile · **Dossier :** `scenarios/tache-ssh-hardening/`

## Énoncé

Objectif : connexion par mot de passe interdite, root uniquement par clé, 3 tentatives maximum, X11 désactivé.

⚠ Ne casse pas la connexion par clé de root : c'est elle qu'utilise le site.
