# localhost ne répond plus

**Type :** Panne · **Difficulté :** facile · **Dossier :** `scenarios/localhost-broken/`

## Énoncé

Ticket : « Les applications n'arrivent plus à joindre les services locaux via `localhost`, alors que `127.0.0.1` fonctionne. »

Objectif : `curl http://localhost` affiche la page d'accueil Nginx.
